방이 만들어지지 않을 때 · 서버 실행 방법

PC에서 시작: ZIP 압축 해제 → START_GAME_WINDOWS.bat 실행(Windows), 또는 ./start_mac_linux.sh 실행(Mac/Linux). Node.js 20 이상 필요.

이후: 브라우저에서 http://localhost:3000을 열고 온라인 1:1 → 새 방 만들기.

다른 기기: 서버 PC와 같은 Wi-Fi에 연결하고, 서버 PC의 IP 주소로 http://PC_IP:3000 접속. 휴대폰의 localhost는 휴대폰 자신을 가리킵니다.

다른 장소의 친구: 서버를 공개 HTTPS/WSS 호스팅에 배포해야 합니다. ZIP은 배포용 소스이며 이미 공개된 서버를 제공하지는 않습니다.
